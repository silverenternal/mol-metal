# FIX-M3 — 队列内金属标签的可解释方差上限

日期：2026-10-19
状态：DONE（下界可识别，R² 上限不可识别，排序上限可界定）

## 问题

FIX-M2 之后决策层仍是 0.1186 / top-1 0.566，所有融合都无效。在再投入目标函数之前，
必须先回答：**这是数据噪声封顶，还是模型没把信号提出来？**

估计量是队列内方差（同一 ligand、cell line、DOI、time 的 y 方差）。它分成三块：

```
var_within = 金属主效应 + 队列×金属交互 + 测量噪声
```

只有交互项能改变队列内排序；金属主效应在每个队列里都一样，排序时抵消。

## 结果（MEASURED）

### 1. 可识别的量

| 量 | 值 |
|---|---|
| 评估队列 / 单元 | 424 / 848 |
| 队列内方差 | 0.09455 |
| 金属主效应占比 | **3.4%**（真实信号的下界） |
| 交互 + 噪声占比 | 96.6% |

### 2. 噪声估计：双峰，且不在评估队列里

| 量 | 值 |
|---|---|
| 有重复的单元 | 304（663 行，359 df） |
| 池化 σ | **0.2114** |
| 组内方差中位数 σ | **0.0265** |
| p90 σ | 0.3301 |
| 落在 424 个评估队列内的重复单元 | **3 / 848** |

池化值和二十分位值差 12 倍——重复单元的方差是双峰的，不能外推。
评估队列里几乎没有重复，所以**噪声水平对这批数据不可识别**。

**R² 上限在 0–99.2% 之间不可识别。** 任何单点估计都是假设的产物（NEG-23）。

### 4. 但排序指标几乎不随噪声塌缩

排序是序数任务。单次测量噪声只会让完美模型从 1.0 降到 0.70–0.95，而不是降到 0。
在 σ ∈ [0.027, 0.36] 的整个合理区间：

- 完美模型 top-1 ∈ [0.700, 0.949]
- 完美模型 regret ∈ [0.001, 0.106]
- 当前最好（`lgb_tree`）：top-1 **0.566**，regret **0.1186**

**当前模型在任何合理噪声下都低于上限。** 要让当前成绩等于上限，噪声必须：

- top-1 需要 σ ≥ **1.24**（IC50 约 17 倍误差）
- regret 需要 σ ≥ **0.395**（约 1.9 倍于最保守的池化估计 0.211，2.1 倍于跨论文 0.186）

### 5. 独立核对：跨论文重复

同一 ligand + metal + cell line 在不同 DOI 的重复：15 对可比较，
top-1 一致 13/15 = **0.867**（Wilson 95%: 0.621–0.963），跨论文 σ = 0.186。
样本很小且有选择偏差，只能作为方向性旁证：金属排序在配体+细胞系层面是可重复的。

## 诚实读数

1. **数据不是绑定约束。** 这是本波次最重要的一条：排序上限高于当前模型，且盈亏平衡噪声
   远高于任何可辩护的估计。
2. **但也不能说「模型很差」到什么程度。** R² 上限不可识别，交互方差可能是 0.09 也可能是 0。
   只能说余量存在，大小未知。
3. **无法区分「表示不足」与「目标不对」。** 上限分析只排除了噪声，没有排除特征信息量。
   这正好是下一步 pairwise 目标要回答的问题。
4. **跨论文排序一致性（0.867）是方向性支持，不是结论**——只有 15 对，且这些论文很可能相关。
5. **要识别 R² 上限，需要在 424 个评估队列内补约 200 个组内重复自由度**
   （约 200 个单元测两次），当前只有 3。这是数据采集问题，不是建模问题。
