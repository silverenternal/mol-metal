# MET-6 — 金属感知消融

**日期**：2026-10-19
**状态**：DONE / PASS
**脚本**：`molmetal/scripts/msrs_metal_ablation.py`
**测试**：`molmetal/tests/test_msrs_metal_ablation.py`（9 个，全过）
**产物**：`metrics/by_metric/msrs_metal_ablation.json`
**耗时**：1,270 s（CPU，8 worker；18 次模型拟合 + 200 次置换）

## 为什么做

MET-2 测到「加 state + coord 块 → R² +0.0544（ligand）/ +0.0423（DOI）」。
这只说明**块**有用，没有说明增益来自**金属信息**：金属标签本身是一个
LightGBM 类别特征，state 块又几乎是金属的确定性函数。要主张「金属感知」，
必须逐块拆开，并给一个置换零分布。

## 做法

同一批折、同一 seed、同一 LightGBM 参数（`n_jobs=1, deterministic`）。九个臂：

| 臂 | ECFP4 | state | coord | metal code | cell code |
|---|:-:|:-:|:-:|:-:|:-:|
| `full` | ✓ | ✓ | ✓ | ✓ | ✓ |
| `no_metal_code` | ✓ | ✓ | ✓ | — | ✓ |
| `no_state` | ✓ | — | ✓ | ✓ | ✓ |
| `no_coord` | ✓ | ✓ | — | ✓ | ✓ |
| `no_state_coord` | ✓ | — | — | ✓ | ✓ |
| `metal_blind` | ✓ | — | — | — | ✓ |
| `no_complex` | — | ✓ | ✓ | ✓ | ✓ |
| `cell_blind` | ✓ | ✓ | ✓ | ✓ | — |
| `ligand_only` | ✓ | — | — | — | — |

两个置换零分布，各 100 次，同折同 seed：

- `metal_label`：只打乱金属标签（重建类别编码），state/coord 保留。
- `metal_block`：金属编码 + state + coord **同一行置换**一起打乱。

p = (1 + #{null ≥ observed}) / (1 + n)。判据：ligand 协议上
`R²(full) − R²(metal_blind) ≥ 0.05` 且 `p_block < 0.01`。

## 判定

**PASS。** metal-blind 掉 **0.0683**（CI [0.0516, 0.0903]）≥ 0.05，
`metal_block` 置换 p = **0.0099** < 0.01。DOI 协议独立复现：掉 **0.0693**
（CI [0.0509, 0.0884]）。

## 诚实读数

1. **金属信息是承重的，而且这是少数跨协议稳定的结论。** 0.0683（ligand）与
   0.0693（DOI）几乎相同——金属消融的代价不随论文留出而缩小。此前所有
   「表示增益」类结论在 DOI 上都会缩水（+0.0544 → +0.0423），这一条没有。
2. **但细胞系是同等量级的杠杆。** 去掉 cell code 掉 **0.0629**（ligand）/
   **0.0442**（DOI），和去掉全部金属块（0.0683/0.0693）几乎一样大。
   所以正确的主张是「金属在配体与细胞系之外仍有增量」，不是「金属让模型变好」。
   池化 R² 里有很大一块是细胞系基线。
3. **金属标签本身几乎冗余。** 只去掉类别编码，R² 只掉 0.0064（ligand，CI
   [0.0014, 0.0111]）和 0.0053（DOI，CI 含 0，p=0.178）。金属身份是由
   state/coord 的连续描述符携带的，one-hot 只是把同一信息又说了一遍。
   这直接回答了「是不是 one-hot 在起作用」——不是。
4. **state 比 coord 重要，coord 单独不显著。** 去 state 掉 0.0272/0.0196；
   去 coord 掉 0.0130/0.0103，两个协议的 CI 都擦到 0。两者合起来
   0.0544/0.0423，略大于各自之和（0.0402/0.0299），有轻微超加性。
5. **没有配体结构也能拿到 0.42。** `no_complex`（只有 26 列金属/细胞特征）
   在 ligand 协议上 R² = 0.4186；`ligand_only`（只有 ECFP4）也是 0.4200。
   两半各自约 0.42，合起来 0.5556。模型近似可加，且**每一半都单独解释了
   四成方差**——这是「池化 R² 不等于配体结构预测能力」的最直接证据。
6. **p 值卡在分辨率下限。** 100 次置换下最小可能 p 是 1/101 = 0.0099；
   两个零分布都是 0/100 超阈，所以报出的 0.0099 是「至少这么小」，不是精确值。
   要区分 p=0.005 与 p=0.0099 需要 500+ 次。判据 p<0.01 恰好卡在边界上，
   这一点必须写明，不能把 0.0099 当成精确测量。
7. **`metal_label` 的 p 也 <0.01，但效应量只有 0.0114。** 统计上可检测、
   实践上可忽略。不要把「标签显著」误读成「标签重要」。
8. **GNN 未重跑。** MET-1 已证明树是决策变量（GNN 单模在 10/10 组合里输给树），
   且 GNN 消费同一组 state/coord 块；树上的块级结论给出融合模型能恢复的上界。
   这一点写在 artifact 的 `design.gnn_note` 里。

## 对主表的影响

- **C2（金属状态/配位是承重的）从「只有树上的 ligand vs +metal」升级为
  「最终模型逐块消融 + 置换零分布 + 双协议复现」**，可以进主表。
- 主表写法：metal-blind −0.068 [0.052, 0.090]，置换 p<0.01；DOI 独立复现
  −0.069 [0.051, 0.088]。
- 必须同时写 cell-blind −0.063，否则「金属感知」会被读成「模型的主要能力」。
- 「金属 one-hot 是承重的」这一说法**不能写**：它的增量只有 0.006/0.005。
