## §2 Method (active learning, similarity-based)

### §2.1 Algorithm

1. Load MetalCytoToxDB Rh real train cohort (n=794: 413 active + 381 inactive)
2. Compute Morgan fingerprints (radius=2, nBits=2048) for all real compounds + 500 synthetic compounds
3. For each synthetic compound `s`:
   - `max_sim_active(s)` = max Tanimoto similarity to 413 real actives
   - `max_sim_inactive(s)` = max Tanimoto similarity to 381 real inactives
   - `diff(s)` = `max_sim_active(s) - max_sim_inactive(s)`
4. Rank all 500 synthetic compounds by `diff` descending
5. **Top 250** by diff → label = 1 (active)
6. **Bottom 250** by diff → label = 0 (inactive)

### §2.2 Empirical observation (the reason for diff-based ranking)

The 500 Wf-131 P2 synthetic Rh compounds (generated by closure BFS) are **structurally different** from MetalCytoToxDB Rh real compounds (which include coordination complexes, salts, etc.). As a result:

| Statistic | Value |
|---|---|
| max_sim_active distribution median | 0.18 |
| max_sim_active distribution max | 0.20 |
| max_sim_inactive distribution median | 0.24 |
| max_sim_inactive distribution max | 0.30 |
| Pearson r(active_sim, inactive_sim) | 0.95 |
| diff distribution range | [-0.108, +0.002] |
| 423/500 compounds more similar to inactive than active | (structural bias) |

A hard threshold (e.g. `max_sim_active >= 0.30`) would label **zero** compounds as active because the absolute similarity never reaches 0.30. The diff-based ranking works around this fundamental limitation by providing **relative discriminative signal** even when absolute similarity is low.

## §4 Honest framing (per `party-twenty-spirit` §3.5)

1. **Similarity-based label is proxy, NOT wet-lab validation.** The 250 "actives" share chemotype similarity with 413 real actives but have NOT been tested for actual cytotoxicity. The cohort is for training-time augmentation only.
2. **Catherine 6/6 PASS guarantees structural validity, NOT activity.** Closure theorem correctness does NOT imply real binding.
3. **Diff-based ranking is a workaround for low absolute similarity.** The 500 synthetic compounds have low Tanimoto similarity to real compounds (median 0.18), so absolute thresholds cannot separate actives from inactives. Diff-based ranking provides discriminative signal but the cohort is fundamentally **not publication-grade** without wet-lab validation.
4. **Structural bias toward inactive**. 423/500 compounds are more similar to real inactives than real actives. This means our "active" cohort is the LEAST inactive-like 250 compounds — not necessarily actually active. The label is **proxy**, NOT ground truth.
5. **Scaffold-split verified.** scaffold_overlap_count = 0 (no scaffold leak between synthetic and real cohorts).
6. **The Wf-131 P2 regression was structural, not statistical.** Even with the new balanced labels, Rh fold AUC is expected to recover only partially. The fundamental ceiling is set by:
   - n=794 small real cohort
   - Low absolute similarity (synthetic ≠ real chemistry)
   - Closure-BFS synthetic generation ≠ real coordination chemistry
