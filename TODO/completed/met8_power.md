# MET-8 — 统计功效与最小可检测效应

**日期**：2026-10-19
**状态**：DONE / PASS
**脚本**：`molmetal/scripts/msrs_power.py`
**测试**：`molmetal/tests/test_msrs_power.py`（8 个，全过）
**产物**：`metrics/by_metric/msrs_power.json`
**输入**：MET-2 / MET-3 / MET-5 / MET-6 的 CI（只读，不重算）

## 为什么做

MET-2/3/5 报了一串 null：DOI R² 0.3321、Δ 符号 0.6193、决策 regret −0.0034。
**没有 MDE，null 无法解释**——是「真的没有效应」还是「样本量不够，看不见」？
MET-8 把每个主指标的 CI 换成标准误，再给出 80% power、单侧 α=0.05 下的
最小可检测效应与所需 DOI 数。

## 做法

- 由 CI95 反推标准误：`sd = (hi − lo) / (2 × 1.96)`。
- `MDE(n0) = (z₀.₉₅ + z₀.₈₀) × sd = 2.4865 × sd`。
- 样本量换算：`MDE(n) = MDE(n0) × √(n0/n)`；
  `n_req = n0 × (MDE(n0) / effect)²`。
- `n0` 一律是 **DOI 聚类数**，不是行数。
- 目标效应按「差值」定义：符号 0.65−0.5 = 0.15；R² 0.50−0.3321 = 0.1679；
  regret 0.10；表示增益 0.05。
- **Caveat**：百分位 bootstrap CI 不是严格正态，CI→sd 是近似；同一近似用在
  所有指标上，所以「哪些 null 是功效不足」的相对判断稳健，绝对 MDE 带这个误差。

## 判定

**PASS（交付）。** 7 个主指标全部给出 MDE、观测效应、是否够功效、检测观测
效应与目标效应所需的 DOI 数。

## 诚实读数

1. **决策层的 null 不是功效不足。** 62 个 DOI 下 MDE = **0.050**，远小于目标
   0.10。如果真实增益有 0.10，这项研究**应该**能看见。没看见，说明真实增益
   低于 ~0.05。这是「确实没有」而不是「样本不够」。
2. **但观测到的 0.0034 小到任何现实样本都测不出。** 要检测它需要
   **13,571 个 DOI**——是现有 62 个的 219 倍、全部语料 1,784 个的 7.6 倍。
   换句话说，模型在决策层的优势不只是不显著，而是**远在任何可操作样本量之下**。
3. **Δ 符号的判据恰好卡在 MDE 上。** MDE = 0.130（即准确率 0.630）；门槛 0.65
   是效应 0.15，只需 **40 个 DOI** 就能检测——现有 53 个足够。观测效应 0.119
   （准确率 0.619）则需 64 个。所以「没到 0.65」是真 miss，但「0.619 显著高于
   0.5」也确实成立（CI 下界 0.5085）。两句话同时为真，不矛盾。
4. **「比恒零预测器好 4%」在统计上不可见。** MAE 改善 0.021，MDE 是 0.0766，
   要 706 个 DOI。MET-3 的这条读数只能作为描述，不能作为主张。
5. **DOI R² 的 miss 是真的。** MDE 0.0643，距离 0.50 目标差 0.168——262 个 DOI
   就能判定「低于目标」，现有 1,784 个 DOI 绰绰有余。不能把 0.3321 说成
   「样本不够」。
6. **表示增益与金属消融都够功效。** MDE 0.019 / 0.024，观测 0.042 / 0.069，
   分别需要 362 / 211 个 DOI。这是项目里少数「效应大于 MDE」的正结果。
7. **决策/符号的有效样本是 ~60 篇论文，不是 1,784。** 只有 61–62 个 DOI 同时
   测了 ≥2 种金属（或能构成配对），R² 与消融用得上全部 1,784 个。两个数字
   不能混用——这也是为什么 R² 的 CI 比 regret 的 CI 窄。
8. **MDE 随 √n 收缩。** 要把 MDE 减半需要 4 倍 DOI：决策 regret 从 0.050 降到
   0.025 需要 ~248 个 DOI，降到 0.0125 需要 ~992 个。以现有语料，这个方向
   不值得继续投入。

## 对主表的影响

- 每个 null 后面必须附 MDE。写法：「regret 差 −0.003（MDE 0.050，62 DOI），
  即真实增益 <0.05」比「不显著」信息量大得多。
- 「Δ 符号 0.62」的写法：效应 0.119，MDE 0.130（53 DOI），门槛 0.15 可检测
  （需 40 DOI）——所以这是真 miss，不是功效问题。
- 「比恒零好 4%」只能写进描述性段落，并注明 MDE 0.077 / 需 706 DOI。
- 主表可以加一列「MDE」，直接展示每个主张的可检测性。
