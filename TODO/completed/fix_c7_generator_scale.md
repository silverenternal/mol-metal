# FIX-C7 — 生成线的 SA 数字来自一个只训练了 1% 语料的模型

**日期**：2026-10-20
**状态**：DONE / **重新归因（联合门槛仍 NOT SUPPORTED）**
**脚本**：`molmetal/scripts/c7_scale_matched_pools.py`（复用 `cfm_sa_yield_audit.pool_report`）
**测试**：`test_c7_scale_matched_pools.py`（9 个，全过）
**产物**：`metrics/by_metric/c7_scale_matched_pools.json`
**成本**：CPU，0 GPU，秒级

## 问题

C7 的可写数字是「SA 6.4423（真实 tmQM 5.0269）、QED 0.0944（真实 0.2685）、
SA≤4.5 产量 16/2,396 = 0.67%」。这个数字被读成「生成器做不出可合成的金属配合物」。

**但没人查过这些分子是哪个模型生成的。** 语料 26,715 个配合物；三个被打分的池来自：

| 池 | 分子数 | 该 run 记录的 `n_train` |
|---|---:|---:|
| `cfm_pcgrad_off_2026_10_15` | 1,175 | **256** |
| `cfm_pcgrad_on_2026_10_14` | 1,155 | **256** |
| `cfm_fullcorpus_2026_10_10` | 66 | **64（1 epoch）** |

97% 的分子来自两个 256 样本的 run。**而这个 run 名字叫 "fullcorpus"。**

盘上还有三个池没被打分，其中两个恰好是全语料 run 生成的
（`cfm_objective_terms_2026_10_11` 43 个、`cfm_fullcorpus_b64_2026_10_11` 40 个，
`n_train` 均为 26,715）。

## MEASURED — 按训练规模分层

| 层 | n_train | 分子 | SA 均值 | QED 均值 | SA≤4.5 | 联合（SA≤4.5 ∧ novelty≥0.90） |
|---|---:|---:|---:|---:|---|---|
| 全语料 | 26,715 | 83 | **5.032 / 5.033** | 0.2042 / 0.2275 | **28 = 33.7% [24.5, 44.4]** | **0** |
| 中 | 2,048 | 12 | 5.650 | 0.2445 | 1 = 8.3% [1.5, 35.4] | 0 |
| 小 | 64 / 256 | 2,396 | 6.442 / 7.474 / 7.548 | 0.0944 / 0.1981 / 0.2001 | 16 = **0.67% [0.41, 1.08]** | 0 |

**两个区间完全不重叠。** 全语料模型的平均 SA 是 **5.032**，真实 tmQM 是 **5.0269**
——差 0.005。QED 从 0.0944 抬到 0.20–0.23（真实 0.2685）。

**SA≤4.5 的产量从 0.67% 变成 33.7%，差 50 倍。**

## MEASURED — novelty 反向

SA≤4.5 子集的平均 novelty：

- 小规模：**0.8677**
- 全语料：**0.6977**

训练得越好，生成物越接近训练集。预注册的联合门槛（SA≤4.5 ∧ novelty≥0.90）
因此 **0/83、0/2,396**——不是因为 SA 不可达，而是**两半随规模反向移动**。

## 判定

**C7 仍是 NOT SUPPORTED，但理由从「架构不行」变成「测错了模型 + 两半互斥」。**

- SA 半边：**可达**（全语料 33.7%，均值与真实语料持平）。
- novelty 半边：**不可达**（0.6977 < 0.90）。
- 联合：**0/83**。

## 诚实读数

1. **已发布的 6.4423 / 0.0944 是 1% 规模模型的性质，不是生成器的性质。** 把它
   写成「我们的生成器做不出可合成配合物」是把训练规模的问题归给架构。
2. **全语料证据只有 83 个分子，且是 epoch 5 与 8（共 50）的快照。** 它确定方向，
   不确定水平：n=83 时 33.7% 的区间是 ±10 个点。
3. **最好的全语料 run 没有权重。** `cfm_r9_fix_v2`（n_train=26,715、type-F1 0.947）
   的目录里**没有 `checkpoints/`**，所以无法重采样；盘上每个池要么早于它，要么
   来自 256 样本的 run。要真正测 C7，必须重训并保留权重。
4. **novelty 的 0.90 门槛比看上去严。** 0.90 意味着对 26k 训练集的**每一个**分子
   Tanimoto ≤ 0.10。门槛不因结果而放宽，但「两半互斥」本身才是结论。
5. **SA 增益尚未与「键更少」分离。** 全语料池是 epoch 5–8 的快照，那两个 epoch 的
   `bond_exact_type_rate` 没有逐池记录；SA 变好有多少来自「发射的键更少」还没排除。
6. **`--sa-penalty` 仍然是零梯度、无可微代理。** 这条旧结论不变：引导解码的机制
   不存在，本轮也没有声称它存在。

## 对台账的影响

C7 改写为：

> **NOT SUPPORTED（联合门槛 0/83）**。SA/QED 强烈依赖训练规模：256 样本模型
> SA 6.44–7.55、SA≤4.5 **0.67% [0.41,1.08]**；全语料（26,715）模型 SA **5.032**、
> SA≤4.5 **33.7% [24.5,44.4]**、QED 0.2042–0.2275（真实 tmQM 5.0269 / 0.2685）。
> 但 SA 子集 novelty 从 0.8677 降到 **0.6977**，联合门槛 **0/83、0/2,396**。
> 因此不能写「生成器做不出可合成配合物」，也不能写「SA≤4.5 可达 33.7%」而不
> 附带 novelty 同时下降。
