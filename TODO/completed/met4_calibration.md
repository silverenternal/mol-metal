# MET-4 — 回归校准与预测区间

**日期**：2026-10-19
**状态**：DONE / NEGATIVE
**脚本**：`molmetal/scripts/msrs_calibration.py`
**测试**：`molmetal/tests/test_msrs_calibration.py`（10 个，全过）
**产物**：`metrics/by_metric/msrs_calibration.json`
**输入**：`results/msrs_generalization/oof.npz`（MET-2 的四协议 OOF，arm = `ligand+both`）

## 为什么做

MET-2 已经证明 DOI 留出下 R² 只有 0.3321。但 R² 只描述点预测，回答不了
审稿人最常问的两个问题：**(1) 这个模型知道自己在哪些样本上不准吗？
(2) 给定一个预测，能给出可信区间吗？** 没有区间，模型只能用于排序，不能用于
「这个配合物比那个好多少」的决策。MET-4 就是补上这两块。

## 做法

- **点校准**：`y ~ a·pred + b`。同时报两个 R²：
  - `r2_point` = 模型自身（对角线）的 R²，尺度错会变负；
  - `r2_fit` = 线性重校准后的 R² = corr²，衡量「排序信息有多少」。
  两者差得远 = 尺度问题；两者都低 = 真没信号。
- **区间**：split conformal，α = 0.10（名义 90%），按 MET-2 的外层折做。
  三种变体：
  - `global`：单一分位数；
  - `metal`：Mondrian，每金属一个分位数（校准行 < 30 回退全局）；
  - `difficulty`：先用 LightGBM 在 OOF 绝对残差上拟合 σ(x)（特征仅
    `prediction / metal_code / cell_line_code`），再对归一化分数做 Mondrian。
- **评价**：coverage（应 ≈0.90）、mean/median width、**Winkler interval score**
  （proper：奖励覆盖也奖励锐度）、PIT 直方图（KS 统计量）。
- **判据**：DOI 协议、`difficulty` 变体，`|coverage − 0.90| ≤ 0.02` **且**
  median width ≤ 1.0 log10。

## 判定

**NEGATIVE。** 两项判据都没过：

- `difficulty` 变体 coverage **0.8789**，偏离 0.90 达 0.0211 > 0.02；
- median width **1.9195** log10，接近门槛（1.0）的两倍。

## 诚实读数

1. **coverage 0.90 几乎不需要技巧。** split conformal 在交换性下按构造就能命中
   名义覆盖率，`global` 变体的 0.9004 不是模型能力，是算法保证。真正有信息量的
   是**宽度**：1.92 log10 意味着区间跨越约两个数量级（上下各一个），对「这个
   配合物比那个好多少」的决策毫无用处。**区间是诚实的，只是诚实到没用。**
2. **宽度不是「调参没调好」，是模型真的这么不准。** DOI 协议残差的标准差给出
   高斯 90% 宽 2.0466，conformal 实测 2.0052——两者几乎相等。任何声称能把这个
   区间收窄的做法，都必须先提高点预测精度，而不是换 conformal 变体。
3. **金属 Mondrian 没有收益。** 它确实把各金属的覆盖率拉平了（0.8987–0.9022），
   但 mean width 仍是 2.01，Winkler 只从 2.7362 降到 2.7328。说明**残差尺度
   与金属基本无关**——金属间的难度差异不是不确定性的主要来源。
4. **difficulty 模型是负收益。** 它把 median width 压了 4.3%（2.0052 → 1.9195），
   代价是 coverage 掉 2.2 个点、Winkler 变差（2.7362 → 2.8587）、PIT KS 从
   0.0012 涨到 0.0439。三个 proper 指标里没有一个赢。原因很直接：σ(x) 是在
   **同一批校准残差**上拟合的，再在这批残差上取分位数，属于信息泄漏，q 被系统性
   压低。**这个变体的失败方式本身就是一条结论：在这个残差信噪比下，学出来的
   难度函数没有泛化价值。**
5. **条件覆盖在「同队列多金属」这一层确实坏了。** 851 行（4.0%）的队列里有 ≥2 种
   金属，coverage 只有 0.81（ligand 协议更差，0.77）。这是交换性被队列结构打破的
   直接证据：同一配体、同一细胞系、同一时间点下不同金属的残差是相关的，而
   conformal 把它们当成独立行。**这是唯一一个「可以修」的方向**——按队列做
   Mondrian，但 851 行分到各队列后每簇太小，本任务不做。
6. **DOI 的下降不是尺度问题。** slope 0.9256（接近 1）、`r2_point` 0.3321 与
   `r2_fit` 0.3363 几乎相等——线性重校准只能把 R² 提高 0.004。MET-2 的
   ligand→DOI 掉 0.22 是**真信号损失**，不是预测被压缩了。
7. **PIT 的平直同样不能当卖点。** `global` 变体 KS = 0.0012 只说明 conformal
   在该折上成立，不说明残差服从什么分布；`difficulty` 的 KS = 0.0439 才是
   它过度自信的量化证据（两端堆积，bin 0 占 11.8% vs 名义 10%）。

## 对主表的影响

- **不能把「不确定性量化」写成贡献。** 区间技术上有效，但宽度 1.9–2.0 log10，
  比 MET-3 报的 Δ 尺度（mean|Δ_obs| 0.53）大三倍以上，无法支撑任何决策声明。
- 主表可以加一行「90% conformal 区间宽度 2.01（DOI）/ 1.65（ligand）」，
  并如实标注为**限制**而非能力。
- 如果审稿人要求区间，答案是：**给得出，但宽到只能覆盖排序不确定性之外的
  全部方差**；改进路径是点预测精度（MET-2 的表示增益），不是区间方法。
- 该结果与 MET-2/MET-3 一致：模型有弱排序信号、几乎没有幅度信号、不确定性
  与金属无关但随队列结构失效。
