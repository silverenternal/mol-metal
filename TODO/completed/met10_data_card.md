# MET-10 — 数据卡与泄漏审计

**日期**：2026-10-19
**状态**：DONE
**脚本**：`molmetal/scripts/msrs_data_card.py`
**产物**：`metrics/by_metric/msrs_data_card.json`
**文档**：`docs/DATASET_CARD.md`（新建）+ `docs/DATA_LEAKAGE_AUDIT.md` §8（新增）

## 为什么做

强指标论文的标配是「数据卡 + 泄漏审计」，但项目里缺这两块对**强模型语料**
的描述。已有的 `docs/DATA_LEAKAGE_AUDIT.md` §1–§7 覆盖分类线、生成线、Pt 和
对照组，没有覆盖 21,404 行 potency 回归语料。MET-2 已经证明 `ligand` 划分会
泄漏论文内一致性，但泄漏的**量化值**一直没有落盘。

## 做法

- 只读 `data/msrs/measurements.parquet`，按强模型的过滤条件取 21,404 行。
- 对四种协议分别计算：**测试行中其分组键也出现在训练折的比例**
  （ligand / DOI / scaffold / cell line），按行加权，并记录每折范围。
- 统计重复键、冲突值、精确重复，以及重复键是否跨折。
- 把去重规则与平票规则写成「实现是什么」而不是「设计意图是什么」。

## 判定

**PASS（文档交付）。** 每个 split 的泄漏量已量化并落盘，论文可直接引用；
去重与平票规则写明。

## 诚实读数

1. **`ligand` 划分的 0.5556 不是泛化数字。** 89.4% 的测试行与训练集共享同一
   篇论文。这正是 MET-2 的 0.5556 → DOI 0.3321（−0.2235，CI 不重叠）的机制。
   数据卡把这个比例写成了可引用的数字，而不是一句「配体分组会泄漏」。
2. **`doi` 划分不是 ligand-disjoint。** 15.4% 的 DOI 留出测试行，其配体在别的
   论文的训练行里出现过。这不是泄漏（不同论文、不同测量），但 DOI 数字不能
   当作「全新配体」的冷启动性能。
3. **`scaffold` 划分介于两者之间**（0.4503），因为它留出了骨架但仍有 65.6%
   的测试行共享论文——完全符合一个「部分泄漏」划分应有的位置。
4. **细胞系在四种协议下都 96–98% 复现。** 池化 R² 里含有细胞系基线的记忆；
   队列内金属排序不受影响（细胞系在队列内是常数），但「新细胞系」的主张
   没有数据支撑。
5. **删失是最大的选择偏差，不是泄漏。** 18.7% 的 potency 行是
   「IC50 > 阈值」，被整行丢弃。模型只估计「已经测出 IC50」的化合物，
   不能解释为对无活性化合物的预测。
6. **重复键跨折为 0 是结构性的**，不是运气：键的每一列都嵌套在四种分组键里。
   因此不需要为去重做额外的分组。
7. **`year` 协议丢掉 69.6% 的行**（14,905 行无 DOI 年份，fold −1）。它是最小、
   最不稳的协议；MET-3 的 Δ 符号 0.4286 只建立在 49 对上。

## 对主表的影响

- 主表必须把 `ligand` 划分标注为**内插**，把 `doi` 标注为**跨论文**；两者不能
  混在同一列里比较。
- 「数据规模 21,404 行 / 5 金属 / 5,861 配体 / 1,784 DOI」可以直接引用。
- 「SMILES 不含金属」这一条支撑 MET-6 的消融解释：ECFP4 块无法夹带金属信息。
- 删失比例 18.7% 必须写进 Limitations；否则审稿人会问「你的模型对无活性
  化合物表现如何」。
