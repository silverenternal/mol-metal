# Open Risks

**Status:** living doc
**Last updated:** 2026-10-19

## R1 — Cite-only SOTA comparison cannot tighten
DiffSBDD ckpt (Zenodo 8183747) + TargetDiff ckpt (Google Drive) +
torch_geometric + torch_scatter ROCm 7.2 wheels all unavailable from the
sandbox. `lambda_vs_sbdd_paper_numbers.md` carries 7 explicit
protocol-mismatch flags; reviewers will challenge any Lambda-Vina claim
until live apples-to-head exists. Mitigation: pending/07 (R4-C 100-pocket
sweep) gives Lambda's own measured column; keep cite-only columns for
DiffSBDD/Pocket2Mol/TargetDiff and flag every row.

## R2 — Vina versus QuickVina protocol parity remains to be measured
QuickVina 2 is installed as the vendored `qvina02` binary and verified against
the official release. Both CLI aliases resolve that same engine. The adapter
now parses real REMARK energies and propagates the configured seed. A paired
Vina/QuickVina N=50 experiment remains required; no direction or magnitude of
bias is claimed before measurement. See `quickvina2_binary_identity.md`.

## R3 — PoseBusters 0/13 pass on CuAAC products
Real negative result documented in `lambda_vs_sbdd_paper_numbers.md`.
Root cause: ETKDGv3+UFF embedding does not reach MMFF94 minimum for
1,2,3-triazoles. Until the engineering fix lands, PoseBusters validity
cannot enter the published metric table. Mitigation: pending/06
(MMFF94OptimizeMolecule swap in embed_3d path).

## R8 — pIC50 predictor Pearson r = 0.407
`h2_pic50_predictor_calibration.md`: Attentive D-MPNN pIC50 predictor
Pearson r = 0.407 on calibration set — below published D-MPNN envelope
(0.78-0.92 on full chem space). Insufficient for absolute IC50 claim;
ranking-only. Phase-2 CFG and reward aggregator using pIC50 should be
interpreted as ranking signal only.

## R9 — Three split labels do not match their implementations (2026-10-19)
`docs/DATA_LEAKAGE_AUDIT.md` (generated by `molmetal/scripts/wf_a51_leakage_audit.py`)
measures no molecule-level leakage anywhere, but three splits claim more separation
than they deliver:

- **CFM v3/v4** — the file is described as a strict Bemis-Murcko split with 0
  scaffold leak. That is true only at the shipped `scaffold_id` key, which is
  stereo-aware and full-complex. Under a desalted stereo-blind ligand key, 73.7 %
  of test rows and 79.6 % of val rows share a scaffold with train. Val clouds are
  what the CFM quality metrics are measured on.
- **MoleculeNet** — `train_moleculenet._bemis_murcko_scaffold` keeps chirality;
  `astartes`, the splitter chemprop moved to, defaults to
  `include_chirality=False`. Our split is therefore easier than the reference,
  and the chemprop comparison is understated by an unmeasured amount.
- **Pt 4-cell** — `load_platinai_4cell_split_table(split_strategy="scaffold_70_10_10")`
  sets `scaffold_id = _stable_hash_int(smiles, 10**8)` and buckets on it: a
  molecule-level hash split. 41.9 % of test rows and 40.8 % of val rows share a
  desalted scaffold with train.

Data-side mitigation landed 2026-10-19: `metalcytotox_5metal_multitask_v5.csv`
is deduplicated (24,483 rows) and split on the desalted stereo-blind ligand
scaffold (17,138 / 2,448 / 4,897; 0 shared scaffolds and 0 shared canonical
SMILES across every pair; all 5 metals in all 3 splits), built by
`molmetal/scripts/wf_a52_rebuild_cfm_split.py`. `p0_scaffold_zero_leak` now
prints the chemical-axis overlap next to PASS so v3/v4 launches stay visible.

Fixed 2026-10-19 (Wf-A53):
- **v5 is now launchable.** `configs/cfm_5metal_v5_full.yaml` points at v5 and
  sets `n_train: 0` / `n_val: 0`, which `_stratified_row_sample` reads as "every
  embeddable row". The default config is untouched so the 2026-10-17 checkpoint
  stays reproducible.
- **The test split has a reader.** `wf_a53_eval_cfm_test_split.py` scores a
  checkpoint on `split=test` read-only and reports whether the split is
  actually held out relative to that checkpoint. MEASURED for the current
  v3-trained checkpoint: `NOT_HELD_OUT`, 609/848 (71.8%) of v5-test molecules
  were seen in v3-train.
- **The two mislabels are now loud at runtime.** `train_moleculenet` prints
  the scaffold key on every split; `train_dmpnn_multitask_wasserstein` prints
  that `scaffold_70_10_10` is a SMILES hash, not a scaffold split.
- **MoleculeNet key aligned to the reference (2026-10-19).**
  `_bemis_murcko_scaffold` now returns `isomericSmiles=False`, which is
  bit-exact with `MurckoScaffoldSmiles(includeChirality=False)` on **every row
  of all four tasks** (2,050 / 1,513 / 41,127 / 1,484). MEASURED
  (`metrics/by_metric/moleculenet_scaffold_key_alignment.json`): scaffold
  counts 1113→1036 (bbbp), 739→671 (bace), 820→788 (clintox), hiv unchanged;
  test-set turnover 63.6-76.5 % / 59.3-83.5 % / 39.3-87.0 % across the five
  seeds. **hiv is bit-identical, so its shipped 0.7900 stands unchanged**;
  bbbp/bace/clintox shipped AUCs are on the old key and must not be cited
  until re-run. Pinned by `molmetal/tests/test_moleculenet_scaffold_key.py`.
- **Pt 4-cell has a real scaffold split (2026-10-19).**
  `--platinai-split-strategy bemis_murcko_70_10_10` groups rows by the
  desalted stereo-blind Bemis-Murcko scaffold
  (`molmetal.data.splits.ScaffoldSplitter`, `largest_first`, seed 0) and
  assigns each scaffold to one split. MEASURED
  (`metrics/by_metric/platinai_4cell_scaffold_split_alignment.json`):
  **0.0 %** of test rows share a scaffold with train, at 13,148 / 1,056 /
  2,108 rows. The legacy `scaffold_70_10_10` is still the default and still
  reproduces the audited 41.9 %, so existing checkpoints stay loadable.
  Pinned by `molmetal/tests/test_platinai_split_strategies.py`.
- **BindingDB now loads (2026-10-19).** The `.data/molmetal/bindingdb_ic50.csv`
  symlink pointed at a 0-byte file truncated 2026-09-30; it now points at
  `bindingdb_ic50_export.csv` (990,630 rows). `_load_real_bindingdb` accepts
  both the TDC export header (`Drug_ID,Drug,Target_ID,Target,Y`) and the
  legacy `ID1,X1,ID2,X2,Y` spelling.
