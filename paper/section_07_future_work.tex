\section{Future work}
\label{sec:future}

The next experiment is a checkpointed, three-seed pilot followed by the
100-pocket sweep once a bounded runtime configuration is established.  Each
run will retain per-pocket failures, seed variance, PoseBusters outcomes, and
the metal-anticancer adjusted metrics alongside the general SBDD thresholds.

Future environment work includes obtaining QuickVina2 for an apples-to-apples
parity check and integrating a genuine learned REINVENT4 scoring plugin in its
isolated environment.  On the modelling side, larger tmQM-pretrained CFG/OT
ablations and multi-GPU execution will improve statistical power.  Broader
metal coverage, explicit DNA-fragment docking, redox and aquation predictors,
and ultimately wet-lab validation are required before therapeutic claims can
be made.
