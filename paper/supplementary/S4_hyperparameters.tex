(ii) train script CLI args; (iii) test seeds / epochs / lr;

canonical value, the source script / config, and the Wf ship

\paragraph{Wf-22 (Metallo drug smoke retrain).}

metallo\_drug\_smoke\_retrain.py}; P0 / P1 fix defaults inherited

bond-head training on; \texttt{BondOrderHead} type learned;
decode smoke cadence every $200$ steps; GPU budget $30$ min
(smoke) / $1$ week (full sweep, \PROJECTED{}).

\paragraph{Wf-2.1 -- Wf-2.3.}
Defaults shared across W2.1 / W2.2 / W2.3: SE(3) Sinkhorn
$T = 200$, $\varepsilon = 0.05$; transport relaxation
$\lambda_{\mathrm{relax}} = 10^{-3}$; 2-PH grid $n_{\mathrm{bins}} =
32$, $K = 32$ SW projections, guardrail cap $200$ off-diag pairs.
All three adapters are CPU-only at the math layer; the W2.x
adapter layer wraps them with batched \texttt{nn.Module}
interfaces.

\subsection*{S4.4 Reproduction environment}
\label{supp:s4-env}

\paragraph{Stack versions.}
The shipped reproduction environment (per
\texttt{molmetal/reports/wf\_extra2\_wire.md} appendix B):
\texttt{uv}-managed Python 3.12; ROCm 7.2 (RX 7800 XT gfx1101
wave64); \texttt{triton-rocm} 3.8.0; PyTorch 2.5.1+rocm7.2; RDKit
2024.9.5; \texttt{flow\_matching} 0.5.0.

\paragraph{Honest framing.}
Shipped reproduction environment is \MEASURED{} (the
\texttt{wf\_extra2\_wire.md} appendix records the exact versions).
A clean-room re-install on the same stack reproduces
\texttt{molmetal/reports/wf\_extra2\_batch/final.md} numbers
bit-for-bit.  Stack-version drift (\texttt{uv} lockfile
regeneration, ROCm patch updates, PyTorch minor-version bump) is
\emph{not} part of the supported reproduction surface.

\paragraph{Summary.}
Hyperparameters for the Wf-1~Wf-22 ship modules, train script
CLI flags, unit-test seeds / epochs / lr, and reproduction
environment versions.  Each entry is tagged \DESIGN{},
\MEASURED{}, or \PROJECTED{} per its provenance.  R18 backlog
hyperparameters (transport relaxation, Bass coupling size, Bergman
anchor points) are \PROJECTED{}; Wf-1 / Wf-3 / Wf-22 ship defaults
are \DESIGN{} (canonical scripts) or \MEASURED{} (R10 / R17
close-out).
