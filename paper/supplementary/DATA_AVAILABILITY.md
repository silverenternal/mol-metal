## 4. Dataset-specific notes

### 4.1 PlatinAI 5K
Original release is CC0; we mirror the SDF + add a scaffold-split CSV
(`data/platinai/scaffold_split.csv`) and a pre-tokenised pickle
(`data/platinai/tokenised.pkl`). Both are part of the public repo.

### 4.2 MetalCytoToxDB 5-metal subset
The original MetalCytoToxDB (Pracht / Bannan / Gale Day groups, 2024) is
released under CC-BY 4.0. We do **not** re-distribute the original SDF
archive; instead, our `data/cytotox.py` ships a downloader script that
fetches from the upstream mirror and then applies the scaffold split +
5-metal filter locally. The scaffold-split indices are part of the repo
(mirror under CC-BY).

### 4.3 tmQM 108K
Originally Balmaseda et al. 2022 under CC-BY. Our repo ships a tokenised
corpus + a learned prior weight file. Raw XYZ is downloaded from the
upstream Zenodo record by `molmetal/data/tmqm.py`.

### 4.4 CrossDocked2020
Used only as a 92-pocket benchmark substrate in Rounds 11–14. We ship
the pocket list + indexed pairs (CC-BY) but not the raw archive. The
downloader is at `molmetal/scripts/fetch_crossdocked.py`.

### 4.5 ChEMBL-derived oracles
We never redistribute ChEMBL rows. Only derived aggregates (mean / std
/ assay-ID hashes) are committed. Per-row queries use the ChEMBL REST API
at runtime; rate-limited.

## 7. Honest caveats

- **ChEMBL redistribution:** we DO NOT redistribute ChEMBL. Any code that
  needs ChEMBL rows must fetch them via the ChEMBL REST API at runtime.
- **MetalCytoToxDB redistribution:** we DO NOT redistribute the original
  SDF; the upstream mirror is the canonical source.
- **Repository URL:** the GitHub URL listed above is **a placeholder**
  pending the actual public release. The actual URL will be inserted in
  the camera-ready and in this file at submission time, alongside a
  release-tagged archive.
- **Bench cache staleness:** the Vina scoring cache shipped in the repo
  is reproducible bit-for-bit on the lab host (REPRODUCIBILITY.md § 1)
  but may differ by floating-point ε on other hardware; we re-derive it
  on first run if `--refresh-cache` is passed.
