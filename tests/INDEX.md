# tests/INDEX.md — Test organization map

Generated by Wf-A2 code consolidation (AGENTS.md §5.8 omega-flow minimalism pattern).

**Pattern**: `tests/` is the **CPU-only regression-guard surface**; GPU-required tests live in `molmetal/tests/` next to the implementation under test (OmegaFold convention).

## Test organization

- **`tests/`** (9 test files + scratch dirs): CPU-only regression-guard tests covering utils, fused ops, and integration of per-Wave audits (Wf-385-A3 SCAFFOLD gate, Wf-394-A3 verify chain, Wf-415-A2 wrapper args, Wf-426-A2 LOI regex, Wf-426-A3 post-fix retrain, Wf-428-B1 catch-up).
- **`molmetal/tests/`** (canonical pytest root per `pyproject.toml [tool.pytest.ini_options] testpaths = ["tests", "molmetal"]`): 558-script-aligned GPU + CPU tests for trainers, benches, skills, retros.

## Conventions

- All test files start with `test_` for pytest auto-discovery.
- Per Wf-405-A1 + Wf-415-A2 + Wf-426-A2 + Wf-426-A3 + Wf-428-B1 + Wf-431-B1: each NEW closeout authors a regression-guard test file (per AGENTS.md §5.5 filesystem-truth + §5.6 atomic_write_file).
- `pyproject.toml [tool.pytest.ini_options] testpaths = ["tests", "molmetal"]` covers both this dir and `molmetal/tests/`.
- Run all CPU-only tests: `molmetal/.venv/bin/python -m pytest tests/ -x --strict-markers`.
