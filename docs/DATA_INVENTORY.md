## 1. What each model actually trains on

### 1.1 Predictive — D-MPNN metal activity

Cohort = `build_paper_cohort(MetalCytoToxDB, metal)` → `collapse_duplicates(tie→active)`; labels are `IC50_Dark_value < 10 µM → active`.

| Metal | Funnel rows | Unique SMILES | Active | Inactive |
|---|---:|---:|---:|---:|
| Ru | 15,799 | 4,793 | 1,557 | 3,236 |
| Ir | 3,674 | 1,281 | 655 | 626 |
| Rh | 951 | 334 | 170 | 164 |
| Os | 966 | 333 | 155 | 178 |
| Re | 666 | 250 | 75 | 175 |
| **Total (per-metal sum)** | | **6,991** | | |

A SMILES can appear under more than one metal, so the per-metal sum is not
a count of distinct molecules. Evaluation: `StratifiedKFold(n_splits=5)` ×
seeds `[42,43,44,49,123]`, no fixed holdout — every molecule is tested in
one fold.

**Leakage (measured, `docs/DATA_LEAKAGE_AUDIT.md`):** the raw SMILES are canonical and unique within each metal cohort (0 multi-string molecules, 0 exact duplicates after collapse), so there is **no molecule-level train/test leak** (0.00 % under both the random and DOI-grouped protocols). The random CV is nevertheless **in-domain by scaffold**: 74.8–85.7 % of test rows share a Bemis-Murcko scaffold with train (45.7–64.2 % under DOI-grouped 10-fold). It is a random-split AUC, not a scaffold-generalisation estimate.

### 1.2 Generative — CFM 5-metal

- Rows **26,632**, unique SMILES **6,743**, cell lines **744**
- Metals: Ru 18,987, Ir 4,546, Rh 1,118, Os 1,113, Re 868
- In-file scaffold split: train 18,137, test 5,736, val 2,759
- Activity: 0 17,471, 1 9,161

The CFM is generative: there is no held-out property test set. Quality is
measured by decoding validation clouds (validity, ring profile, novelty,
docking), not by a train/test AUC.

**Leakage (measured):** the in-file `scaffold_id` is stereo-aware and full-complex (counterions/solvent included). It is disjoint across train/val/test (0 shared) and no SMILES carries more than one split label. At the **desalted, stereo-blind ligand-scaffold** level, however, 222 scaffolds are shared between train and test (73.7 % of test rows) and 131 between train and val (79.6 % of val rows). Removing stereo alone leaves 30 shared scaffolds (4.2 % of test rows); the gap is dominated by counterion/solvent fragments. The split is not a ligand-scaffold OOD split.

### 1.3 Platinum external evaluation

- Rows **17,735**, unique compounds **3,630**, cell lines contributing Pt rows **369**
- Rows with SMILES **17,735** / 17,735; training-ready (value + SMILES) **15,953**
- **No split column** — a pool, not a partition. Duplicate `(compound_code, cell_line)` rows **3,668**; exact duplicate `(code, cell, value)` rows **987**. 296/3,555 unique SMILES fail RDKit parsing.
- **Pt 4-cell training cohort** (`.data/molmetal/platinai_4cell.csv`, a different file from the pool): the loader's `split_strategy` is named `scaffold_70_10_10` but sets `scaffold_id` to a stable hash of the SMILES string, i.e. a molecule-level split. 172 desalted scaffolds are shared between train and test (41.9 % of test rows) and 40.8 % of val rows. Canonical overlap is 0.

### 1.4 Controls

- **NCI-60 precious-metal panel**: 7,823 rows / 5,207 unique SMILES / 9 cell lines. Split is a Bemis-Murcko scaffold split on unique SMILES, seed 0: train 4,860 / val 115 / test 232 molecules. It is a **subset of MetalCytoToxDB** (5,207/5,207 canonical molecules in the 5-metal pool, 5,183 in CFM), not an independent corpus. The older 3,645/521/1,041 figure came from the pre-BLK-PA12 splitter (empty scaffold key).
- **MoleculeNet** (bace / bbbp / clintox / hiv): scaffold 70/10/20, 5 seeds. The split key is **stereo-aware**. At the stereo-blind level up to 0 scaffolds are shared between train and test (0.0 % of test rows, bace); desalting adds a counterion-driven component up to 52 scaffolds (hiv), with a row-level maximum of 35.3 % (bbbp). No canonical molecule overlap.
- **DrugOOD lbap**: 266,522 rows with iid/ood train/val/test as a column; used as the OOD control, not as a headline result. train vs ood_test has 0 canonical and 0 scaffold_split_id overlap; train vs iid_test shares scaffold IDs by design.

## 3. Notes per dataset

- **`metalcytotox_raw`** (ACTIVE) — Raw Krasnov corpus. Predictive cohorts are derived from this by build_paper_cohort() + collapse_duplicates(tie->active).
- **`cfm_5metal_v3`** (ACTIVE) — Canonical CFM cohort (configs/cfm_5metal_default.yaml). Scaffold split column is carried in-file; it is stereo-aware and full-complex, not a desalted ligand-scaffold split (see docs/DATA_LEAKAGE_AUDIT.md).
- **`cfm_5metal_v4`** (ACTIVE) — Same rows as v3 plus lowercase smiles/metal aliases and source. Used by 10 configs; kept because both are wired. Same split caveat as v3.
- **`cfm_5metal_v5`** (UNUSED) — Deduplicated rebuild (24,483 rows) with a desalted stereo-blind ligand-scaffold split: 17,138/2,448/4,897, 0 shared scaffolds and 0 shared canonical SMILES across every split pair, all 5 metals in all 3 splits. Built by wf_a52_rebuild_cfm_split.py. No training config points at it yet, but its test split now HAS a consumer: wf_a53_eval_cfm_test_split.py scores a checkpoint on split='test' read-only (4,888 of 4,897 rows embed; 4,888 carry bond truth).
- **`cfm_5metal_v2`** (SUPERSEDED) — Same 26,632 rows as v3, differing only in column naming (lowercase smiles/metal vs canonical SMILES_Ligands/Metal). Use v3.
- **`cfm_5metal_v1`** (SUPERSEDED) — Pre-v2 cohort; only legacy configs.
- **`pt_biodata_all`** (ACTIVE) — 17,735 real MB-Finder Pt IC50 rows, 100% SMILES-joined (Wf-A46/47/48/49). No split column; 3,668 duplicate (code, cell) rows and 987 exact duplicate measurements. 296 unique SMILES fail RDKit parsing.
- **`pt_biodata_raw`** (ACTIVE) — All-metal harvest summary: 485 cell lines / 30,185 rows.
- **`pt_4cell_synthetic`** (DO-NOT-TRAIN) — SYNTHETIC pIC50 (meta says 'synthetic IC50 labels for pipeline test'). Its ~0.50 AUC is a null test, not a measurement.
- **`pt_real_label_pool`** (SUPERSEDED) — Real labels but 1/2,053 rows carry SMILES; superseded by pt_biodata_all.
- **`pt_4cell_real`** (ACTIVE) — REAL structures + REAL IC50 labels for the four PlatinAI cell lines, built from the 2026-10-19 MB-Finder harvest by build_platinai_4cell_real_cohort.py. 1,966 compounds / 3,144 unique (compound, cell) pairs from 4,370 raw biodata rows (A549 871, A2780 860, A2780cis 600, MCF-7 813); 953 compounds cover >=2 cells, 56 cover all four. Unit is uM per the Rusanov 2025 SI figure captions; pIC50 = 6 - log10(IC50_uM). 1,935 unique SMILES, not 1,966: 28 SMILES appear under 2-3 compound codes (59 rows), with per-cell labels up to 1.45 log units apart. The split groups by scaffold, so duplicates cannot cross train/test, but the compound count overstates chemical diversity by 1.6 %. This is the cohort that can replace pt_4cell_synthetic (which carries simulated labels).
- **`pt_4cell_real_trainer`** (ACTIVE) — The same 1,966 compounds projected into the schema load_platinai_4cell_split_table accepts (SMILES_Ligands + pIC50_{a549,a2780,a2780cis,mcf7} + metal=Pt). A projection, not a second cohort: no measurement is added, dropped or imputed, and a compound with no IC50 for a cell line has an empty cell that the loader turns into NaN and masks out of the loss. Exists so the D-MPNN trainer can be pointed at REAL labels without hand-editing a CSV.
- **`moleculenet_bace`** (ACTIVE) — Scaffold 70/10/20, 5 seeds.
- **`moleculenet_bbbp`** (ACTIVE) — Scaffold 70/10/20, 5 seeds.
- **`moleculenet_clintox`** (ACTIVE) — Scaffold 70/10/20, 5 seeds.

Split is a Bemis-Murcko scaffold split on unique SMILES, seed 0: 4,860/115/232 molecules, which is 7,320/160/343 rows (93.6/2.0/4.4 %) — five of nine cells have < 30 test rows. ## 5. Known gaps

Open:

- **NCI-60 9-cell split is not 70/10/20 by rows.** The shipped
  `scaffold_70_10_10` protocol budgets fractions in *scaffold counts*, so
  the largest 70 % of the 1,151 scaffolds (94.3-100 % of every cell's
  rows) go to train and test receives the singleton leftovers:
  **7,320 / 160 / 343 rows** (93.6 / 2.0 / 4.4 %). Five of nine cells
  have < 30 test rows (SKOV3 3, DU145 7, HL60 11, PC3 18, A2780cis 28)
  and SKOV3 has 0 val rows. The coverage split
  (`--nci60-split-strategy scaffold_coverage_70_10_20`: 5,371 / 920 /
  1,532 rows, every cell >= 25 test and >= 22 val) is now the loader
  default; the shipped configs pin the legacy protocol. **No model has
  been retrained on the new default yet.** Measured:
  `metrics/by_metric/nci60_split_coverage_audit.json`; risk
  `TODO/risks.md` R11.
- **CFM v3/v4 `scaffold_id` is a full-complex, stereo-aware key**, so
  73.7 % of test rows share a desalted scaffold with train.
  `cfm_5metal_v5` fixes this (0 shared scaffolds) but no checkpoint has
  been trained from it; see section 3.
- **`pt_biodata_all` is a pool, not a partition.** 17,735 rows, 3,668
  duplicate `(compound_code, cell_line)` rows and 987 exact duplicate
  measurements; 296 unique SMILES fail RDKit parsing. The 4-cell cohort
  filters and median-collapses these (counted in its `.meta.json`), but
  the raw pool itself is unchanged.
